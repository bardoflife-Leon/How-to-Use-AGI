# How to Use AGI

How to Use AGI is an early-stage documentation project for collecting practical guidance, examples, and workflows for working with advanced AI systems.

The repository is being bootstrapped. There is no application code yet, and the first goal is to establish a clear home for future guides, corrections, examples, and discussion.

## Project Goals

- Document useful patterns for applying advanced AI tools to real work.
- Keep examples practical, inspectable, and easy to adapt.
- Track open questions and corrections through GitHub issues.
- Review proposed additions through pull requests before they are merged.

## Current Status

This repository currently contains the project license and contribution scaffolding. Content, examples, and supporting materials can be added through future pull requests.

## Contributing

Contributions are welcome when they improve clarity, accuracy, or usefulness.

Before opening a pull request:

1. Keep changes focused on one topic or correction.
2. Explain why the change is useful.
3. Include sources, context, or examples when they help reviewers understand the update.
4. Use the pull request template checklist.

For questions, documentation requests, or corrections, open an issue with enough context for maintainers to reproduce the concern or evaluate the suggestion.
